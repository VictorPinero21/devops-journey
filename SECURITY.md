# Security Policy

## Supported versions

This repository contains documentation and configuration for a personal learning portfolio. Only the latest version on the `main` branch is maintained.

## Reporting a vulnerability

If you find a security issue, please **do not open a public issue**.

Report it privately instead:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem and how to reproduce it.

This is a personal project, so I answer on a best-effort basis, but I will review every report.

## Scope

- Exposed secrets, tokens or personal data in the repository.
- Vulnerable dependencies or insecure workflow configuration.
