## Labels

| Label      | Use                                      |
|------------|------------------------------------------|
| `setup`    | Initial repository configuration         |
| `security` | Branch protection, Dependabot, policies  |
| `template` | Issue and pull request templates         |
| `project`  | Roadmap projects and the Projects board  |
| `docs`     | Documentation and site content           |
| `bug`      | Something is broken                      |
